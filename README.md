A tiny Python program (standard library only, deterministic, no network) that
writes a single-line resignation letter — the funniest one it can — to
`entry.txt` in the directory named by the `MAKEFUN_OUTPUT_DIR` environment
variable (default `/output`).

The line:

> I hereby resign as your human cannonball — I'm tired of a job where the only way to get ahead is to get fired.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
